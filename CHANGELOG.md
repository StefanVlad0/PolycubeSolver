# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-07-27

First public release.

### Added

- 3D polycube editor - sculpt pieces and irregular target shapes by clicking cells
- Soma Cube preset (7 pieces, verified 11520 / 480 / 240 solution counts)
- Exact-cover solver (Dancing Links) in a Web Worker with live progress
- Solution browser with navigation and explode slider
- Symmetry dedupe modes: raw, rotations, rotations + reflections
- Optional piece reflections
- Startup intro animation and 3-step onboarding tutorial
- GitHub Pages deploy workflow
- CI workflow (build + Soma solver regression test)
- Contributing guide, issue templates, and PR template
